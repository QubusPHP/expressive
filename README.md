# Database Abstraction Layer

A database abstraction layer toolkit with query builder, schema builder, and ORM (Active Record and DataMapper). 
Relies on PDO connection for pdo_mysql, pdo_sqlite, pdo_oci, pdo_pgsql and pdo_sqlsrv.

## Requirements
* PHP 8.4+

## Installation
```
composer require qubus/expressive
```
